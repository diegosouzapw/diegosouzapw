## What I'm building

OmniRoute gives developers one local endpoint for hundreds of AI providers and models. It
focuses on resilient routing, transparent fallback, token efficiency, open protocols, and
making powerful AI tooling more accessible without hiding operational trade-offs.

Since February 2026, it has grown into a project shaped by hundreds of contributors, with
documentation and community surfaces available across 43 languages.

My current open-source work includes:

- Multi-provider routing and failure recovery.
- OpenAI, Anthropic, MCP, and A2A interoperability.
- Reproducible free-tier, cost, quota, and token-efficiency methodologies.
- Maintainer workflows that preserve contributor credit and keep decisions auditable.
- Documentation, support, and contribution paths for a global developer community.
